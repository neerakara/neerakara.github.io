Understanding high-dimensional embeddings via PCA, t-SNE and UMAP
Note1. Motivation: Understanding learned embeddings

Modern deep learning models transform raw inputs (images, text, etc.) into high-dimensional feature representations. For instance, a vision model might map an image to a 512-dimensional embedding vector, or a language model might encode a sentence as a 768-dimensional feature. These learned representations capture semantic and structural information, but their high dimensionality makes them difficult to visualize and interpret directly.

Key questions we want to answer:

  • Do learned embeddings cluster by class label?
  • Do embeddings separate based on nuisance variables (e.g., lighting, pose, background)?
  • Are there unexpected subgroups or failure modes?
  • How does embedding structure evolve during training?

Dimensionality reduction techniques project high-dimensional data into 2D or 3D space, enabling visual exploration of embedding structure. The three most widely used methods are PCA, t-SNE, and UMAP, each with different strengths and trade-offs.

Note2. Principal Component Analysis (PCA)

PCA finds the linear directions of maximum variance in the data. It represents the data as a linear combination of orthogonal basis vectors (principal components), ordered by the amount of variance they explain.

How it works

Given data \(\mathbf{X} \in \mathbb{R}^{n \times d}\) (where \(n\) is the number of samples and \(d\) is the dimensionality), PCA computes the covariance matrix \(\mathbf{C} = \frac{1}{n}\mathbf{X}^\top\mathbf{X}\) (assuming centered data) and finds its eigendecomposition \(\mathbf{C} = \mathbf{V}\mathbf{\Lambda}\mathbf{V}^\top\). The eigenvectors \(\mathbf{V}\) are the principal components, and the eigenvalues \(\mathbf{\Lambda}\) indicate the variance explained by each component.

To reduce to \(k\) dimensions, we project the data onto the top-\(k\) eigenvectors: \(\mathbf{Z} = \mathbf{X}\mathbf{V}_k\), where \(\mathbf{V}_k \in \mathbb{R}^{d \times k}\) contains the first \(k\) columns of \(\mathbf{V}\).

Strengths

  • Fast and scalable: Efficient for high-dimensional data, \(O(d^2n + d^3)\) complexity
  • Deterministic: Same result every time
  • Interpretable: Principal components are linear combinations of original features
  • Preserves global structure: Captures large-scale variance patterns

Limitations

  • Linear: Cannot capture nonlinear structure in data
  • Distance metric: Uses Euclidean distance, which may not be meaningful in all spaces
  • Outliers: Sensitive to outliers that can dominate principal directions

When to use PCA

  • Initial exploratory analysis of embedding structure
  • When linear structure is sufficient (e.g., checking if classes are linearly separable)
  • When speed and reproducibility are priorities
  • As a preprocessing step before other methods
Note3. t-Distributed Stochastic Neighbor Embedding (t-SNE)

t-SNE is a nonlinear method that preserves local structure by modeling pairwise similarities between points. It aims to ensure that points close together in high-dimensional space remain close in the low-dimensional projection, while allowing distant points to be placed far apart.

How it works

t-SNE models the similarity between points in high-dimensional space using a Gaussian distribution centered at each point. For points \(i\) and \(j\), the conditional probability that \(i\) would pick \(j\) as a neighbor is: \[p_{j|i} = \frac{\exp(-\|\mathbf{x}_i - \mathbf{x}_j\|^2 / 2\sigma_i^2)}{\sum_{k \neq i} \exp(-\|\mathbf{x}_i - \mathbf{x}_k\|^2 / 2\sigma_i^2)}\] where \(\sigma_i\) is chosen adaptively based on local density (controlled by the perplexity hyperparameter). The joint probability is \(p_{ij} = \frac{p_{j|i} + p_{i|j}}{2n}\).

In the low-dimensional space, t-SNE models similarities using a heavy-tailed Student’s t-distribution: \[q_{ij} = \frac{(1 + \|\mathbf{z}_i - \mathbf{z}_j\|^2)^{-1}}{\sum_{k \neq l}(1 + \|\mathbf{z}_k - \mathbf{z}_l\|^2)^{-1}}\]

The embedding is optimized by minimizing the KL divergence between \(p\) and \(q\): \[\text{KL}(P \| Q) = \sum_{i \neq j} p_{ij} \log \frac{p_{ij}}{q_{ij}}\]

Strengths

  • Excellent local structure preservation: Keeps similar points close together
  • Nonlinear: Captures complex manifold structure
  • Clear cluster visualization: Produces well-separated, interpretable clusters

Limitations

  • Global structure: Does not reliably preserve global distances or cluster relationships
  • Slow: \(O(n^2)\) complexity, impractical for very large datasets without approximations
  • Stochastic: Different runs produce different results
  • Hyperparameter sensitivity: Perplexity strongly affects the result (typical values: 5–50)
  • Fixed embeddings: Cannot embed new points without rerunning the entire algorithm

When to use t-SNE

  • Finding fine-grained clusters within classes
  • Identifying outliers or mislabeled examples
  • Visualizing local neighborhood structure
  • When dataset size is moderate (\(n < 10{,}000\) without approximations)
Note4. Uniform Manifold Approximation and Projection (UMAP)

UMAP is a more recent method that balances local and global structure preservation. It is based on manifold learning and topological data analysis, constructing a high-dimensional graph representation and optimizing a low-dimensional layout.

How it works

UMAP models the data as lying on a Riemannian manifold and computes a fuzzy topological representation. For each point, it connects to its \(k\) nearest neighbors with edge weights based on distance: \[w_{ij} = \exp\left(-\frac{\max(0, \|\mathbf{x}_i - \mathbf{x}_j\| - \rho_i)}{\sigma_i}\right)\] where \(\rho_i\) is the distance to the nearest neighbor and \(\sigma_i\) is a normalization constant.

The low-dimensional embedding is initialized (often with a spectral method) and optimized to match the topological structure using a cross-entropy-like objective similar to t-SNE, but with different probability distributions that better preserve both local and global structure.

Strengths

  • Fast: \(O(n \log n)\) complexity via nearest-neighbor graphs and stochastic optimization
  • Scalable: Handles large datasets efficiently
  • Better global structure: Preserves more of the global topology than t-SNE
  • Out-of-sample extension: Can embed new points without full retraining
  • Flexible: Works well with various distance metrics

Limitations

  • Stochastic: Like t-SNE, results vary between runs
  • Less interpretable: Mathematical foundation is more complex
  • Hyperparameter sensitivity: Results depend on n_neighbors and min_dist parameters

When to use UMAP

  • Large-scale embedding visualization (\(n > 10{,}000\))
  • When both local clusters and global structure matter
  • Embedding new data points into an existing projection
  • When speed is important
Note5. Practical workflow and interpretation

Typical analysis pipeline

  1. Start with PCA: Quick check for linear structure, outliers, and major patterns
  2. Apply UMAP or t-SNE: Reveal fine-grained nonlinear structure
  3. Color by metadata: Label points by class, training set split, or nuisance variables
  4. Iterate on hyperparameters: Try different perplexity (t-SNE) or n_neighbors (UMAP) values

What to look for

Class structure:

  • Do same-class examples cluster together?
  • Are there within-class subclusters (different modes of the class)?
  • Which classes are confused (close in embedding space)?

Nuisance variables:

  • Do clusters correspond to non-semantic factors (e.g., background, lighting, camera angle)?
  • Are nuisance factors separable from class structure?
  • This can reveal biases or spurious correlations in learned representations

Training dynamics:

  • How does cluster structure change across training epochs?
  • Do clusters become more separated over time?
  • Are there collapse modes where many classes merge?

Common pitfalls

  • Over-interpretation: Clusters in 2D may not reflect true high-dimensional structure
  • Distance interpretation: Distances between clusters in t-SNE/UMAP are not meaningful
  • Hyperparameter dependence: Always try multiple settings
  • Computational cost: t-SNE on large datasets requires approximations (e.g., FIt-SNE)
Note6. Comparison summary
Method Speed Preserves local Preserves global Deterministic Scales to large \(n\)
PCA Fast No Yes Yes Yes
t-SNE Slow Excellent Poor No No (w/o approx.)
UMAP Fast Very good Good No Yes

Rule of thumb:

  • Use PCA first for a quick overview
  • Use t-SNE when you need the best local cluster visualization and have moderate data size
  • Use UMAP when you need scalability and care about both local and global structure

# t-SNE

embeddings_tsne = tsne.fit_transform(embeddings)

# UMAP
